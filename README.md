## What's here

Each folder in this repo is one self-contained skill, prompt, or project. Every one follows the same format — see [TEMPLATE.md](./TEMPLATE.md) — so you always know what to expect: what it does, what problem it solves, and how to use it even if you've never touched a terminal.

## Skills
